## 채보 결과의 의미

자동 채보 결과는 **확인·수정이 필요한 초안**입니다. 사용자가 확인한 고정 BPM, 선택한 박자표, 16분음표 격자를 기준으로 만듭니다.

| 단계·악기 | 기본 처리 |
|---|---|
| 음원 분리 | SAM Audio |
| 기타·피아노·신디 등 다성 음원 | [Spotify Basic Pitch](https://github.com/spotify/basic-pitch)의 음정·시작·종료 추정 |
| 보컬·베이스 | CPU pYIN 단선율 추적, 필요하면 `화음 포함`으로 전환 |
| 드럼 | 타격 시각과 종류 추정 |
| BPM·박 위치·가사 | CPU 분석으로 초안 제안 |

상세 엔진과 설정은 [오디오 엔진](audio-engines.md)을 참고하세요. 건반은 음역 기준 두 보표 분리와 수동 손 지정을 지원하지만, 실제 연주자의 손이나 독립 성부를 인식하는 것은 아닙니다. MusicXML은 외부 악보 편집기에서도 수정할 수 있습니다.

## 기본 조작과 저장

악보에서 `악보 직접 수정`을 열어 마디별로 교정합니다.

| 조작 | 동작 |
|---|---|
| 빈 격자 칸 클릭 | 음표 추가 |
| `●` 또는 TAB 숫자 | 음표 시작 위치; 클릭하면 선택 |
| `—` | 앞 음표의 이어짐; 쉼표가 아님 |
| 음표 길이 또는 `1칸 늘리기` | 이어짐 길이 변경 |
| 시작 음표 더블클릭 / 삭제 버튼 | 음표 삭제 |
| 마디 번호·이전/다음 / 미리보기 마디 클릭 | 해당 마디로 이동 |
| 격자 방향키 | 칸 이동 |
| `Ctrl/Cmd+S` / `Ctrl/Cmd+Z` | 편집기 안에서 저장 / 실행 취소 |

한 칸은 16분음표입니다. 같은 음정 또는 같은 TAB 줄의 시간 겹침은 허용하지 않습니다.

선택한 음표의 음정/드럼 종류·시작·길이·세기, 악센트·스타카토·테누토를 수정할 수 있습니다. 마디 복사, 제목·BPM·구간 표시·마디 아래 메모도 지원합니다.

### 일괄 수정

- 음표 목록에서 `Shift+클릭`하거나 일괄 수정의 마디 범위를 선택합니다.
- 충돌·범위 초과가 있으면 전체 변경을 거절합니다.
- 음정 이동은 운지 배정만 초기화합니다. 드럼에는 반음 이동을 적용할 수 없습니다.
- 새 줄·페이지 시작은 현재 마디에 지정하며, 2마디 이후부터 가능합니다.

### 원본·임시본·충돌 방지

- 미리보기와 실행 취소는 서버 파일을 덮어쓰지 않습니다. `저장하고 반영`해야 저장됩니다.
- `채보 원본`으로 자동 채보 최초 결과를 복원할 수 있습니다. 복원도 저장 전에는 서버를 바꾸지 않으며 실행 취소할 수 있습니다.
- 재채보는 수정본을 대체하므로 화면 확인과 API의 `overwrite_edits` 동의가 필요합니다.
- 저장 전 편집본은 브라우저에 임시 보관합니다. 최신 서버 버전과 일치할 때만 복원을 제안하며, 브라우저 저장소를 지우면 임시본도 사라집니다.
- 여러 탭의 덮어쓰기는 revision 검사로 차단합니다. `JSON 보관`은 수동 백업이며 **JSON 가져오기는 아직 지원하지 않습니다.**

## 드럼 표기와 연결선

직접 입력은 킥·스네어·하이햇·오픈 하이햇·크래시·라이드·하이/미드/플로어 탐을 지원합니다. 기본 CPU 분류기는 킥·스네어·하이햇만 추정하고 동시 타격 후보를 독립 검출합니다. 다른 종류는 직접 입력하거나 별도의 전용 모델이 필요합니다.

- 심벌·스네어의 기둥은 위쪽, 킥은 아래쪽으로 분리합니다. 빔을 MusicXML에 명시합니다.
- `음표 연결선(빔)`에서 1박/2박 묶음을 선택합니다. 드럼 기본값은 2박으로, 8분음표 네 개를 연결합니다.
- 16분음표의 첫 번째 빔은 2박, 두 번째 빔은 1박 단위로 나누고 쉼표·긴 음표에서 끊습니다. 빔 설정은 음표 길이·MIDI를 바꾸지 않습니다.
- 기존 저장 악보의 빔은 자동 덮어쓰지 않습니다. `음표 연결선(빔) → 2박씩`을 선택해 저장하면 새 묶음을 적용합니다.
- 하이햇만 있는 마디도 5선 보표를 유지합니다. 가사가 있는 쉼표 마디는 다중 쉼표로 축약하지 않습니다.

새 자동 드럼 악보는 감쇠 시간 대신 같은 성부의 다음 타격·마디 끝·최대 한 박 묶음 길이까지 음가를 정리합니다. 연속 8비트/16비트가 짧은 음표와 불필요한 쉼표로 갈라지는 것을 줄이기 위한 처리입니다.

타격 시각·종류·세기는 유지하고 MIDI 노트 종료는 정리된 길이를 따릅니다. **이미 저장했거나 MusicXML로 가져온 음표 길이를 다시 정리하지는 않습니다.**

## TAB 우선 편집

| 항목 | 지원·동작 |
|---|---|
| 튜닝 | 베이스 4/5/6현, 기타 6/7현 프리셋과 Drop D |
| 줄·프렛 | 1번 줄이 가장 높은 줄, 0프렛은 개방현 |
| 기본 배치 | 새 악보는 TAB 위·오선 아래; 기존 저장본 순서는 유지 |
| 배치 변경 | `위쪽 보표` 선택 후 저장 |
| 음정 | 오선은 일반적인 옥타브 이조 표기; MIDI·운지는 실제 소리의 음정 유지 |
| 카포 | 0~12, 프렛은 카포 기준 상대 위치 |

실제 음정은 `튜닝 + 카포 + 프렛`입니다. [MusicXML 카포 규칙](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/capo/)에 따라 개방현 음정을 올립니다. 카포 변경은 음표의 소리를 유지하고 운지만 다시 제안합니다.

- 빈칸을 누르면 입력 프렛·길이로 추가합니다. 숫자를 누르면 속성을 편집하고 더블클릭·삭제 버튼으로 지웁니다.
- 줄 변경은 음정을 유지하는 프렛을 계산하고, 프렛 변경은 음정도 함께 바꿉니다. 한 줄에서 겹치는 음표는 저장할 수 없습니다.
- X 음표(뮤트)와 정수 반음 벤딩을 지정할 수 있습니다. 합성 미리듣기는 이를 단순 근사하며 실제 주법 음색이 아닙니다. MIDI는 기본 음정·길이·세기를 유지합니다.
- 자동 운지는 줄 수·음역·동시 발음·대략적인 손 이동을 고려한 제안이지 실제 연주자의 운지 인식이 아닙니다.
- 범위를 벗어난 음을 임의로 옥타브 이동하지 않습니다. 미배정 음은 오선에 남지만 TAB에서 제외되므로 **TAB만 출력하기 전에 미배정 수를 확인**하세요.
- 튜닝 변경·운지 초기화 후 저장하면 다시 배정합니다. 기존 프로젝트의 TAB 데이터는 편집기를 열 때 추가되고 저장 이후 일반 보기·내보내기에 반영됩니다.

이 **격자 편집기**에는 해머링·풀링·슬라이드·프리벤드/릴리스 편집이 없습니다. MusicXML 기반 원본 보존 편집기는 [조건부 연결 주법 편집](score-import.md#연주-기호와-연결)을 별도로 지원합니다.

## 박자표와 변박

지원 박자는 **2/4·3/4·4/4·6/8·9/8·12/8**입니다. 새 채보·빈 악보에서 먼저 선택하거나, `박자표 · 변박`에서 적용할 마디를 지정합니다.

박자 변경 시:

- 뒤에 지정해 둔 변박은 기존 **마디 번호**에서 계속 적용합니다.
- 음표 시작·길이·가사 시간은 유지하고 마디선만 다시 나눕니다. 마지막 마디 부족분은 쉼표로 채우며 음원 길이는 바꾸지 않습니다.
- 구간 메모와 수동 줄·페이지 시작은 기존 마디 첫 위치를 포함하는 새 마디로 옮깁니다. 같은 마디에 모인 메모는 합치되 글자 제한을 넘으면 거절합니다.
- 새 첫 마디로 옮겨진 줄·페이지 시작은 첫 페이지 자체에 포함됩니다. 안내·실행 취소·미리보기·저장 충돌 검사를 유지하므로 인쇄 전에 위치를 확인하세요.
- 짧아진 마디에 음표가 들어맞지 않으면 마디 붙여넣기를 거절하며 대상 음표를 지우지 않습니다.

BPM은 모든 박자에서 **4분음표 기준**입니다. 6/8의 점4분음표 60은 앱의 BPM 90과 같습니다. MusicXML의 [sound tempo](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/sound/)와 MIDI도 같은 기준이며, 가져오는 고정 메트로놈의 점음표 템포는 환산합니다.

6/8·9/8·12/8 빔은 8분음표 세 개씩, 두 번째 빔은 8분음표 단위로 나눕니다. MusicXML·MIDI에 마디별 박자표를 기록합니다. 기존 저장본은 4/4로 읽으며 음표·revision·채보 원본 파일은 바꾸지 않습니다.

## 가사와 합주 진입 위치

실제 음원은 프로젝트의 `가사 타임라인`에서 CPU 인식·검토·전체 적용을 합니다. 합성 샘플에는 실제 노랫말이 없어 자동 인식하지 않습니다.

`가사 · 보컬 진입`에서 각 파트의 음절·단어·짧은 문장·진입 힌트를 마디와 시작 칸에 배치할 수 있습니다. 쉼표 구간도 지원합니다. 결합 악보는 아래쪽 보표 밑에, 단독 악보는 해당 보표 밑에 표시하고 실제 MusicXML `<lyric>`로 내보냅니다.

긴 가사는 짧게 나누고 2마디/큰 악보 출력을 권장합니다. A/B/Intro 같은 구간 표시와 마디 아래 메모도 직접 입력할 수 있지만, 메모는 정밀한 가사 음절 배치가 아닌 마디 단위 힌트입니다. 메모는 인쇄·MusicXML에도 반영됩니다.

### LRC 가져오기

| 항목 | 규칙 |
|---|---|
| 형식 | 일반 LRC `[00:12.34]가사`, 반복 시간 태그, `[offset:250]` 밀리초 오프셋 |
| 크기 | 최대 512KB, 항목당 80자 |
| 시간 배치 | 원본 음원의 시간에 원래 채보 BPM·악보 시작 오프셋을 적용하여 16분음표 칸에 반올림 |
| 범위·충돌 | 곡 밖 항목 제외, 동일 칸 충돌 거절 |
| 공통 가이드 | 같은 칸의 단어를 합치되 80자 초과 시 거절 |

나중의 BPM 편집은 가사·음표 칸이나 원본 음원 재생 위치를 옮기지 않습니다. 확장 LRC 음절 시간 태그와 SRT는 미지원이며, 정확한 합주 위치는 음원과 비교해야 합니다.

### 다른 악보에 복사

저장 후 `저장한 가사를 다른 악보에 복사`를 사용하면 대상의 **가사만 대체**하고 음표·TAB·메모·자동 채보 원본은 유지합니다.

대상의 revision이 변경되어 오래된 탭의 덮어쓰기를 막습니다. 채보 BPM이 다르면 원래 시간으로 환산하며 충돌·범위 초과 시 전체 복사를 거절합니다. 복사 후 파트마다 독립 수정할 수 있고 자동 동기화되지는 않습니다.

## 스타일·재생·내보내기

| 기능 | 동작·주의점 |
|---|---|
| 출력 스타일 | 합주용 / 기본 / 큰 악보, 한 줄 2/4마디 |
| 작은 화면 | `가독성 확대`로 좌우 읽기; 이 보기 확대는 인쇄를 바꾸지 않음 |
| 레이아웃 | 화면 크기 설정은 보기·인쇄에 적용, 저장한 출력 스타일은 MusicXML에도 기록 |
| 내보내기 | `저장하고 반영` 후 편집기를 닫아 MusicXML·MIDI·ZIP 다운로드 또는 인쇄/PDF 저장 |
| BPM 편집 | 악보·MIDI 템포만 변경; 원본 음원 속도 유지 |

다른 편집기는 레이아웃을 다르게 해석할 수 있고, 복잡한 마디는 겹침을 피하려고 목표보다 적게 배치될 수 있습니다. 참고 악보의 로고·워터마크·QR·곡 내용은 제품에 복사하지 않았습니다.

`악보 듣기`는 저장 전 음표도 간단한 합성음으로 재생합니다. 현재~마지막 마디 범위, 0.5/0.75/1/1.25배속과 반복을 지원하고 재생 마디를 강조합니다. 정지·편집·마디 이동·화면 종료 시 재생도 중단합니다. 실제 악기 사운드폰트는 아닙니다.

원본·분리 음원 플레이어는 최초 채보 BPM·시작 오프셋·저장한 변박으로 현재 마디를 강조합니다. 합성 재생과 음원 재생은 서로 중지해 겹치지 않습니다. 구간 템포 변화 기반 정밀 동기화·음표 단위 커서는 아직 없습니다.

## 아직 지원하지 않는 편집

- 박자표·변박·마디 첫 박 자동 검출, 구간별 템포 지도, 조성 추정
- 실제 연주 기반 건반 손·독립 성부 인식
- 오선 음표 직접 드래그, 잇단음표·못갖춘마디·5/8·7/8·자유 박자
- 격자 편집기에서의 반복기호·다이내믹·코드 기호

이 편집기는 마디 중심 교정 도구이며 범용 악보 제작 프로그램은 아닙니다. 복잡한 표기를 가진 기존 악보는 [원본 보존 경로](score-import.md)를 사용하세요.
