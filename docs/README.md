1. **README:** 제품 소개·대표 기능·빠른 시작·중요한 한계만 유지합니다.
2. **사용 가이드:** 지금 실제로 쓸 수 있는 기능과 설정을 해당 주제의 문서에 반영합니다.
3. **CHANGELOG:** 변경 날짜 아래에 추가·수정·검증 내용을 짧게 적고 관련 PR/문서를 연결합니다. 작업 중인 내용은 머지된 기록과 구분합니다.
4. **연구 기록:** 상세 수치·실패 사례·기각한 방법·재실행 명령은 날짜가 있는 기록에 남깁니다. 오래된 테스트 수치를 최신 상태로 덮어쓰지 않습니다.
5. **경계 유지:** 기능 테스트 통과, 모델 실행 성공, 실제 음악 정확도 개선은 서로 구분합니다. 비공개 악보·음원·모델·토큰은 문서와 Git에 포함하지 않습니다.
