Independent drum recognition research — 2026-10-06

Decision
The default ADT_STR recognizer and all existing scores are unchanged. An
independent STRUM V14 onset detector + single V12c classifier now runs locally
and produces review JSON. It is not the complete STRUM game-chart pipeline,
and upstream headline accuracy numbers must not be attributed to this adapter.

Primary sources checked
1. https://github.com/opria123/strum
   Source README declares MIT. Its reported game-chart benchmark uses ±100 ms
   and global-offset search; ours uses fixed ±50 ms without reference shifts.
2. https://huggingface.co/opria123/strum
   Model card declares MIT; only two checkpoint files were downloaded (564.6 MB).
3. https://github.com/MZehren/ADTOF
   Independent CRNN alternative, original CC BY-NC-SA 4.0. Not installed.
4. https://github.com/xavriley/ADTOF-pytorch
   Author-linked port, but separate port license was not clear. Not installed.
5. https://github.com/ddman1101/Separate-and-detect
   https://huggingface.co/ddman1101/Separate-and-Detect
   Recent five-stem diffusion approach with MIT-labeled main weights. Needs
   separate VAE/vocoder dependencies and substantial runtime work; not installed.
6. https://github.com/Music-and-Culture-Technology-Lab/omnizart
   Official README warns about ARM macOS compatibility. Not installed.
7. https://magenta.tensorflow.org/oaf-drums
   Independent Onsets-and-Frames/E-GMD model, legacy TensorFlow runtime; not installed.

Adapter choices fixed before evaluation
- Follow pinned executable source: 44.1 kHz, not README's 22.05 kHz description.
- Ten-second overlapping onset windows; complete coverage includes short tails.
- Zero-pad classifier boundary windows instead of silently ignoring them.
- Onset threshold .5 from checkpoint config; all class sigmoids .5, no local sweep.
- Two-pass neighboring-onset context, single V12c (not seven-model ensemble).
- No pattern filling, rhythmic quantization, class-forcing, spectral override,
  reference-derived timing shift, or silent removal of implausible co-occurrences.
- Hi-hat articulation, snare technique, exact tom tuning, and dynamics are not
  recognized. GM pitches are representative transport labels; amplitude is fixed.

Measured results
Reused MDB recordings: 10 distinct songs, 14 conditions (10 drum-only + 4 mixes).
The four mixes are the SAME recordings, not four additional independent songs.
These are development diagnostics, not held-out generalization results. MDB
recording/mix audio is NOT a SAM separation benchmark. Labels remain the existing
human references; dataset has noncommercial restrictions already recorded locally.

Exploratory independent-confirmation follow-up
Only an existing rejected one-of-three ADT hat can be proposed if an independent
STRUM hat is within 50 ms. Existing baseline hats reserve nearby evidence, one
independent hit cannot support multiple suggestions, original ADT time/subtype
is retained. This preserves baseline events, but does not confirm the subtype.
Policy was fixed before the follow-up comparison, after the model comparison;
it is explicitly exploratory and the reused validation IDs are not new holdout.

Across 14 conditions the hypothetical additions were 53:
- Kit-11 labels: +37 correct, +16 extra errors.
- Five-family labels: +42 correct, +11 extra errors.
- Rock: +10 correct, zero extra.
- Country1 mix: +2 correct, +9 extra (kit-11).
- Disco: +2 correct, +3 extra.
Thus shipped output is REVIEW SUGGESTIONS ONLY, with no automatic score mutation.
False-positive and unconfirmed-articulation warnings are included in every report.

.venv/bin/python scripts/prepare-drum-challenger.py --output .data/strum-runtime
.data/strum-runtime/.venv/bin/python scripts/transcribe-drums-challenger.py \
  --source .data/strum-runtime/source --weights .data/strum-runtime/weights \
  --audio /path/to/excerpt.wav --output /new/path/to/review.json
Inputs: mono/stereo local excerpts <=60 seconds; never overwrites output files.
The review-drum-challenger.py CLI requires frozen baseline-run audio/transcription
hashes as well as the independent artifact; it refuses unbound/different audio.
