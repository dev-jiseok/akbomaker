### 1. PDF 인식·표기 보존형 미리보기

- 대역 엔진 자동 테스트로 업로드·원본 보존·다중 결과·검토/편집 연결·취소/실패·표기 보존을 확인했습니다. 실제 엔진 인식 성능 시험이 아닙니다.
- Orca 브라우저에서 TAB·오선·가사, 자작 셋잇단음표·슬러·다이내믹·도돌이표의 보존형 SVG 렌더링을 이미지로 확인했습니다.

### 2. 원본 보존 편집기

- 6개 악기 음악 구조 유지, 선택 필드 외 불변, 대용량 MXL, 동시 revision 충돌, 저장 실패 원자성, undo/redo, 스타일 변경 시 원본 비교 갱신을 검사했습니다.
- 자작 6파트 MusicXML로 기타/베이스 TAB·드럼 빔·건반 두 보표·피아노 페달·보컬 멜로디/가사를 브라우저에서 확인했습니다.
- 기타 E4의 1번 줄 0프렛 → 2번 줄 5프렛을 저장·재열기·undo/redo했습니다. 드럼 하이햇 → 스네어의 위치·음표머리 변경과 보컬 가사 수정도 확인했습니다.
- 저장·편집·표시 연결 검증이지 실제 PDF 인식 정확도 평가가 아닙니다.

### 3. 별도 스타일 화면·선택형 수정 확장

- 6개 악기의 쉼표/음표 왕복·영구 undo, 오선/TAB 양방향 유일 연결, 중간 direction이 있는 화음 잠금, 삭제 후 임시표 유지, 드럼 표기 견본 검증을 확인했습니다.
- 스타일 전후 음악 데이터 비교 및 PDF 좌표 작업·다운로드를 검사했습니다.
- 브라우저에서 별도 메뉴·기본 편집 도구 숨김, 기타 2번 줄 5 → 7프렛의 E4 → F♯4 반영과 저장/undo, 렌더된 TAB 숫자 복원, 가로 넘침 없음을 확인했습니다.

### 4. 수동 입력 TAB 검수 연결

## 실제 Audiveris 드럼 PDF 시험

### 실행 조건

- 사용자 동의 후 공식 Audiveris 5.11.0 macOS arm64와 영어 legacy OCR을 Git 제외 경로에 설치했습니다.
- 원본 보존·시각 비교 절차에 따라 제공된 드럼 `Creep [TAB].pdf` **첫 페이지만** CPU 처리했습니다.
- 직접 실행 시간은 18.34초였습니다.
- 웹 업로드 → 원본 미리보기 → 실제 엔진 실행 → 원본/보정 MusicXML 저장도 확인했습니다.

### 발견한 오류

| 확인 항목 | 실제 결과 |
|---|---|
| 첫 4마디 킥 | 원본 16타 → 인식 13타 |
| 열린 하이햇 | 2타를 닫힌 하이햇으로 오인식 |
| 타격 위치 | 타이밍 오류 확인 |
| 전체 출력 | 24마디·309개 음표 중 5마디 이후 256개가 일반 음정으로 잘못 출력 |
| 리듬 경고 | 7·13·16·18마디 |
| 가사 | 누락·오인식 확인 |
| 호환성 보정 | MIDI 번호 47개만 변경; 위 인식 결함은 해결하지 않음 |

**실행 성공은 정확도 성공이 아닙니다. 이 PDF는 검수 없이 편집 가능한 드럼 악보로 사용할 수 없습니다.**

웹 결과에서 원본/보정본 다운로드, 리듬·악기 경고, 파트 선택, 표기 보존형 SVG 미리보기를 확인했습니다. 음표·빔·가사는 표시되지만 OMR 오류도 그대로 남습니다. 드럼 요청 결과는 새 프로젝트에서도 드럼으로 선택하며 자동 적용하지 않습니다.
